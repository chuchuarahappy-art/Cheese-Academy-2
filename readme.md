##制作LPの説明
    チーズ職人養成学校「チーズアカデミー」の受講者を募集するランディングページです
##工夫した点・こだわった点
    ヘッダーの固定
    スクロールしてもロゴとナビゲーションが画面の上部に残るよう、position: fixedで固定しました
    シンプルにわかりやすいLPにしました
##今後トライしたいこと
    スマートフォン対応：レスポンシブ機能
    メニューボタンの実装、カート機能や決済機能の実装など
    リターゲティングタグなど、どうやって実装しているのかなど、色々気になり始めました
##備考,（感想、シェアしたいこと等なんでも）
    CSSの「;（セミコロン）」や「,（カンマ）」の打ち忘れが、デザイン全体を壊してしまうことを学びました。また、皆さんの作品をみて画面の上部を固定する設定（position: fixed）にトライできました。
    ユーザーの使いやすさには、技術的なことはもちろんUIも大事だと改めて感じました
